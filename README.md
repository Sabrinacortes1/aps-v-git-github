# aps-v-git-github
APS V — Controle de Versão com Git e GitHub

Sobre o projeto
Este repositório foi criado como parte da APS V, do curso de Análise e Desenvolvimento de Sistemas.
O objetivo é desenvolver conhecimentos práticos sobre controle de versão utilizando Git e GitHub.

Objetivos

Compreender o funcionamento do Git e GitHub.
Aprender a criar e gerenciar repositórios.
Conhecer os principais comandos do Git.
Realizar commits e acompanhar alterações.
Desenvolver habilidades de organização e versionamento de projetos.

Comandos Git

Comandos e Funçãos

git init = Inicializa um repositório.

git clone = Clona um repositório.

git status = Verifica o estado dos arquivos.

git add = Adiciona arquivos para preparação. 

git commit = Registra alterações. 

git push = Envia alterações ao GitHub. 

git pull = Atualiza o repositório local.

git log = Mostra o histórico de commits.

Atividade prática - 
Este repositório será utilizado para registrar os conhecimentos adquiridos durante o curso de Git e GitHub, por meio de anotações, exercícios e exemplos práticos.
